# CMMT 회의 자료

이 폴더에 회의 원문을 `.txt` 형식으로 저장한다.

## 파일 규칙

- 원문: 자유로운 이름의 `.txt` 파일
- 회의록: 원문과 같은 폴더의 `<원문명>_회의록.md`
- 예시: `2026-08-26_주간회의.txt` → `2026-08-26_주간회의_회의록.md`

## 회의록 구성

1. 회의 정보: 일시·주제(원문에서 확인되는 범위)
2. 핵심 논의
3. 결정사항
4. 액션 아이템: 같은 담당자의 할 일을 하나로 묶어서 정리
5. 미해결 쟁점

회의 정보에서 참석자와 원문 항목은 제외하고, 액션 아이템에 기한 항목을 두지 않는다. 잡담과 프로젝트 무관 대화는 제외한다. 원문에 없는 결정과 담당자는 추측하지 않으며 불명확한 내용은 `미확정`으로 표시한다.

## Notion 업로드

- Markdown 회의록 작성 후 지정된 Notion `회의 보고서` 데이터베이스에 자동 업로드한다.
- `Doc name`은 회의 날짜의 `YYYY-MM-DD` 형식으로 작성한다.
- 같은 날짜의 페이지가 이미 있으면 새 페이지를 중복 생성하지 않고 기존 페이지를 최신 회의록으로 갱신한다.
- `참석자` 속성은 비워 둔다.
