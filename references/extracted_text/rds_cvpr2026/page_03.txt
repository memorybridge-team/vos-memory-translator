2.2. Dynamic Models
Dynamic models [10, 12, 17, 26, 34, 36–38] selectively
activate only part of their computational pathways (e.g.,
tokens [21, 25, 26, 30, 31, 47, 51] or blocks [2, 13–
15, 17, 20, 26, 35, 45, 48]) to achieve the goal of compu-
tational efficiency, given intermediate features or task com-
plexity as conditions. Unlike traditional static models, these
networks adaptively adjust their components based on dif-
ferent input data, demonstrating strong performance in tasks
such as image recognition [2, 30] and object detection [14].
As for visual segmentation, existing research [26] has in-
tegrated dynamic mechanisms into encoder architectures,
enhancing inference efficiency by skipping redundant mod-
ules. In addition, there are studies [24] that leverage redun-
dancy between consecutive frames, avoiding unnecessary
computation, and reducing latency.
Still, current approaches face challenges in balancing ac-
curacy and efficiency, characterized by their dense rout-
ing,i.e., allocating routers for intermediate features from
all stages. This can introduce repetitive computations and
hinder the actual accelerating effect.
We address these limitations by introducing a Prediction-
Aware Router that jointly takes temporal and visual fea-
tures as input, reaching a dynamic activation decision with
a single routing computation. Additionally, we propose I-
LoRA to enable efficient fine-tuning of dynamic architec-
tures while maintaining performance.
3. Recurrent Submodel Dynamics
Our approach, illustrated in Figure 2, introduces two core
components. First, a Prediction-Aware Router (PAR) dy-
namically selects a submodel for each frame using vi-
sual features and the previous frame’s mask. Second,
Importance-Aware LoRA (I-LoRA) enables efficient fine-
tuning by adapting only the most critical blocks. We detail
the full training and inference process in Section 3.4.
